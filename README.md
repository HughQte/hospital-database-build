This project is practicing building a standard (real-world) hospital database system. 

The system must strictly align with healthcare data standards, privacy regulations, and role-based security architectures.

- Data Standard: HL7 FHIR:
• Patient Resource: Stores demographics (ID, name, DOB, contact).
• Encounter Resource: Tracks hospital visits, admissions, and discharges.
• Observation Resource: Stores vital signs, lab results, and diagnostics.
• Claim Resource: Represents the invoice/data sent to the insurer for payment.
